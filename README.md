# Java Inheritance Programs

This repository contains Java programs demonstrating **Inheritance** in Object-Oriented Programming (OOP).

These programs were created to practice and understand how classes can inherit properties and behaviors from other classes.

## 📚 Concepts Covered

* Inheritance in Java
* Single Inheritance
* Multilevel Inheritance
* Hierarchical Inheritance
* Multiple Inheritance using Interfaces
* Parent and Child Classes
* `extends` keyword
* `super` keyword
* Code Reusability

## 🛠️ Technologies Used

* **Programming Language:** Java
* **IDE:** Eclipse IDE

## 🚀 How to Run

1. Clone or download this repository.
2. Open the Java source files in Eclipse IDE or another Java IDE.
3. Open the desired Java class.
4. Run the program as a Java Application.

## 🎯 Purpose

This repository was created for Java programming practice and to strengthen my understanding of **Inheritance and Object-Oriented Programming concepts**.
